# Agile Final Project

A planning exercise for a back-end e-commerce product catalog, prepared for IBM's Introduction to Agile Development and Scrum course.

This repository contains an educational sprint simulation, not an implemented product. Issue status represents the mock sprint required by the assignment.

## Scope

Ten stakeholder requirements cover product CRUD, positive and negative product preferences, listing and filtering products, cloud hosting, and automated deployment.

## Sprint

- Title: **Sprint**
- Dates: **September 26–October 9, 2026** (two weeks)
- Goal: Deliver the core create, retrieve, update, and delete capabilities.
- Planned work: requirements 1–4, **10 story points**.
- Simulated ending state: requirements 1–2 Done (**5 points**), requirement 3 In Progress (**3 points**), requirement 4 Sprint Backlog (**2 points**).
- Requirements 7–8 are in Icebox. Requirements 5–6 and 9–10 remain in Product Backlog.
- Requirements 9–10 carry the **technical debt** label; the other stories carry **enhancement**.
